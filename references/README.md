## 关键差异：两份规范互相冲突的地方

**这是收录这两份文档最主要的价值** —— 它们证明了「视频生成 Prompt 的写法」不存在通用答案。

### 1. 时间表达方式（直接冲突）

| | MiniMax H3 | Seedance 2.0 |
|---|---|---|
| 时间表达 | **使用绝对秒数**<br>`0-3秒 / 3-7秒 / 7-11秒 / 11-15秒` | **禁止绝对秒数**<br>必须用 `镜头1 / 镜头2 / 镜头3` |
| 原因 | 时间轴是把营销文案转成可执行镜头的手段 | 模型对精确时间支持不稳定 |

**影响**：同一段 Prompt 在两个模型上一个正常、一个结构崩坏。**这是换模型时最容易踩的坑。**

### 2. 素材引用语法

| | MiniMax H3 | Seedance 2.0 |
|---|---|---|
| 引用方式 | `Picture1` / `Picture2` / `Picture3` / `Picture4` | `@图片N` / `@视频N` / `@音频N` |
| 主体绑定 | 在人物设定段落统一描述 | `<主体N>@图片N` 或先定义标签再复用 |
| 特殊约束 | 不使用"某张图"这类含糊称呼 | 禁止裸写 `[asset-xxx]`；`@图片N` 后不能紧接动词 |

### 3. 素材数量策略

| | MiniMax H3 | Seedance 2.0 |
|---|---|---|
| 数量 | 固定四图（商品图1、商品图2、补充图、场景图） | 推荐 4-5 个，**不建议用满上限** |
| 人脸参考 | 未特别说明 | **必须**大头照 + 全身照；**禁用**三视图（易触发 ID 漂移与双胞胎） |

## 两份规范共同强调的（跨模型通用的部分）

以下几条在两份文档中都出现，可以认为是**跨模型通用的原则**：

| 原则 | H3 的表述 | Seedance 的表述 |
|---|---|---|
| **素材角色必须显式声明** | 四图各承担什么角色逐一写清，防止把场景图当商品 | 素材与主体绑定，防止角色串位 |
| **抽象概念要外化为可观察细节** | "有销售感""温柔"转成面对镜头、拿起商品、指向产品、微笑 | "悲伤"转成肩膀颤抖、眼眶泛红、手指攥紧衣角 |
| **人物一致性需跨镜头声明** | 人物设定要作为"全片一致的设定"，不能只在第一个镜头写 | 全程使用同一 `<主体N>` 标签；挂双胞胎兜底 |
| **禁止编造事实** | 价格、功效、品牌、权益不自行补写 | 关键歧义不静默修改，需用户确认 |
| **兜底约束必须挂载** | 人物/商品/包装/文字一致性 + 避免变形乱码 | 画质包 + 稳定包 + 水印Logo兜底为默认必挂 |
| **仅在关键歧义时打断用户** | 四图顺序、人物描述、文案缺失才询问 | 仅方位映射、任务误判、运镜冲突、特征矛盾四类需确认 |

## Seedance 2.0 独有的、值得注意的规则

这些在 H3 文档中没有提到，但对理解视频生成模型的工作方式很有帮助：

**① 空间层 / 时间层的双层理解模型**

> Seedance 2.0 内部把素材拆成「空间层（画面里有什么）」与「时间层（事情如何随时间变化）」两个维度理解。

因此好的 Prompt 不是形容词堆砌，而是**工程型指令**：谁、在什么场景、做什么动作、镜头如何运动、按怎样的顺序发生。

**② 复杂度判定看事件密度，不看素材数量**

从时间维度（是否多事件链/状态转折）和空间维度（是否场景切换/多机位）判断，而不是数素材有几个或分镜有几段。素材数量 ≥4、用户主动写"镜头1/2/3"只是**倾向复杂**的辅助信号。

**③ 任务类型的语法差异会导致误判**

编辑/延长任务如果写成「参考 @视频N」，会被判为参考生成任务，导致模型自由重构而非精确编辑。必须写「严格编辑 @视频N」/「向后延长 @视频N」。

**④ 特殊字符的语义隔离**

| 信息类型 | 符号 |
|---|---|
| 背景音乐 | `（）` |
| 音效 | `<>` |
| 台词 | `{}` |
| 字幕/标题 | `【】` |

**⑤ 动作描述的偏好**

优先低缓连续小动作，规避狂奔/大跳/剧烈翻滚等高爆发动态。这反映了当前视频生成模型在剧烈运动上的能力边界。

## 怎么用这两份文档

**换模型前**：对照「关键差异」一节，确认时间表达、素材引用、素材数量三项策略是否需要调整。

**写新场景的 Prompt 时**：先看「共同强调的部分」（这些跨模型通用），再查目标模型的独有规则。

**遇到无法解释的失败时**：检查是否违反了目标模型的语法约定（如任务类型误判、断句歧义、绝对秒数）——这类问题看起来像效果问题，实际是语法问题。
