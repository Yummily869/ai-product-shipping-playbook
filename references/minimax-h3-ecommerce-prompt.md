# H3 商品四图带货 Prompt

## Inputs to collect

- 四张图片及其顺序：`Picture1=商品图1`、`Picture2=商品图2`、`Picture3=补充图`、`Picture4=场景图`。用户明确的素材角色优先于视觉猜测。
- 人物描述：外貌、年龄、服饰、发型、身份、气质和动作偏好。
- 文案提炼：口播、字幕、卖点、规格、价格、购买引导。用户没有提供的价格、功效、品牌和权益不自行补写。
- 用户指定的时长、画幅、分辨率、平台或风格；未指定时采用 15 秒、9:16、短视频带货质感。

如果四图顺序、人物描述或文案缺失，先询问缺失项；如果只是图片中的文字模糊，不要擅自补全为确定事实。

## Procedure

1. 内部查看四张图，建立素材角色表，不把冗长的视觉分析输出给用户。
   - Picture1：商品图1，优先承载商品/食品真实外观、掰开或食用后的质感及图中可见卖点。
   - Picture2：商品图2，锁定包装、品牌、颜色、版式和可辨认文字。
   - Picture3：补充图，补充手持、独立包装、内部结构、尺寸或细节；只采用确实可见的信息。
   - Picture4：场景图，提供最终拍摄环境、桌面布置、生产/家庭场景和光线氛围。
   原因：H3 需要知道每张图提供什么，避免把包装、场景或补充细节混为同一主体。

2. 将人物描述写成“全片一致的人物设定”。保留用户给出的年龄范围、亚洲女性身份、脸型、肤色、妆容、表情、服装、发型、体态和生活/带货气质；将抽象的“有销售感”“温柔”“自然”转成可观察的面对镜头、拿起商品、掰开食品、指向产品、微笑和购买引导。
   原因：人物描述是 H3 跨镜头保持同一主播的依据，不要只在第一个镜头出现人物设定。

3. 将文案拆成 4 段时间轴，默认使用以下节奏；用户明确给出时长或节奏时覆盖默认值：
   - 0–3 秒：人物面对镜头 + 商品快速亮相 + 原文案中的黄金 Hook；
   - 3–7 秒：商品近景/掰开/拉丝/馅料或口感细节 + 核心卖点；
   - 7–11 秒：多件商品、包装、规格、使用场景或搭配 + 数量/重量/价格等用户已提供信息；
   - 11–15 秒：人物与商品同框 + 原文案中的行动号召。
   每段同时写清画面、人物动作、景别/运镜、普通话口播和字幕。不要把整段文案只放在 Prompt 末尾。
   原因：时间轴让 H3 把营销文案转成可执行的镜头，而不是生成静态商品展示。

4. 按固定结构输出完整 Prompt，依次包含：
   - 视频目标与规格；
   - 四张图片的角色映射；
   - 商品真实性与包装锁定；
   - 全片人物设定；
   - 0–3、3–7、7–11、11–15 秒分镜、动作、口播/字幕；
   - 镜头、光线、声音和整体风格；
   - 一致性与负向约束。
   用 `Picture1`–`Picture4` 与输入顺序对应，不重新编号，不使用“某张图”这类含糊称呼。

5. 对事实边界做检查：商品名称、品牌、口味、数量、重量、价格、功效、包装文字和场景只能来自用户文案或图片中清晰可见的信息。用户文案中的营销夸张语句可以作为口播原文保留，但不要再推导出新的功效或事实。

6. 加入与本任务相关的保护约束：人物面部/发型/服装/体态一致；商品形状、颜色、包装、Logo、文字和馅料一致；四图角色不串位；字幕简短清晰；避免包装变形、文字乱码、手指畸形、人物换脸、商品融化、馅料异常喷溅、场景跳变和额外人物/品牌/设备。不要机械添加与任务无关的限制。

7. 输出前检查：四图顺序是否正确；人物描述和文案是否都进入 Prompt；文案是否分配到时间轴；规格是否明确；是否出现未经用户提供的价格、功效、品牌或权益；是否把 Picture4 的场景错误当成商品；是否仍然保留“可直接提交给 H3”的自然语言格式。

## Output contract

- 默认只输出一段可直接提交给 MiniMax H3 的完整中文 Prompt，不输出内部分析、模板名称、API JSON、上传步骤或调用命令。
- Prompt 默认包含 `15秒`、`9:16`；用户指定的时长、比例、分辨率和平台优先。
- 允许使用短标题或分段换行，但必须把四张图角色、人物设定、时间轴、镜头、口播/字幕和一致性约束写全。
- 用户若要求“提示词和原始输入对比”，再额外列出新增/改写/未改内容；默认不输出对比说明。
- 本 Skill 只生成 Prompt，不执行 H3 API 调用；用户明确要求跑 H3 时，交由对应 API/工具流程处理。

## Failure handling

- 图片数量不是 4 张但用户仍明确要求继续：先说明缺少或多出的素材及其影响；不要假装完成固定四图映射。
- 图片顺序与用户文字冲突：保留冲突点并询问，不擅自选择。
- 图片文字无法确认：写“以参考图可见文字为准”或删除不确定细节，不编造品牌、价格、重量和功效。
- 文案过长无法自然放入 15 秒：压缩重复口语但保留用户指定卖点，并明确字幕简短化；不擅自删除核心购买引导。
- 用户只给人物和文案、没有四张图片：可以说明需要四图后再生成本 Skill 的最终 Prompt；不要用虚构素材替代。

## Canonical structure

```text
基于四张参考图生成一条15秒竖屏电商带货短视频（9:16），[整体拍摄质感]，人物和商品保持全片连续一致。

素材角色严格对应：Picture1为商品图1，[真实商品外观/口感]；Picture2为商品图2，[包装与文字]；Picture3为补充图，[补充细节]；Picture4为场景图，[最终场景与氛围]。商品形状、颜色、包装、Logo、文字和关键细节以参考图为准，不得臆造、替换或改写。

人物：[完整人物描述]。全片始终是同一位人物，面部、发型、服装、体态和气质保持一致。

时间轴与普通话口播/字幕：0-3秒，[Hook画面与动作]，口播/字幕：“[Hook]”；3-7秒，[商品细节画面与动作]，口播/字幕：“[卖点]”；7-11秒，[包装/规格/使用场景]，口播/字幕：“[规格或场景]”；11-15秒，[人物与商品同框和行动号召]，口播/字幕：“[CTA]”。

镜头语言：[景别、运镜、光线、声音、节奏]。字幕简洁清晰，尽量准确呈现上述口播。

一致性约束：[人物、商品、包装、文字、场景和生成质量保护项]。
```

## Example: accepted pattern

Input includes four food-product images, a young female livestream seller description, and a sales script. The output should map the four images explicitly, keep the product packaging tied to Picture2, use Picture1/Picture3 for food texture close-ups, use Picture4 for the setting, and distribute the script across four time segments. It should not output an API request or invent a price/benefit absent from the input.
