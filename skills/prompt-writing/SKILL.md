# Prompt 撰写

把一句话需求转换为可直接使用的完整 Prompt。

---

## Input

用户可以只给一句话，也可以给完整背景。除 [关键歧义](#step-3--关键歧义拦截) 外，缺失信息由本 skill 按规则自动补齐并在输出中披露，**不反复追问**。

典型输入：

```
给我生成一段用于视频复刻的 prompt，视频结构需与参考视频一样，人物替换成我自己
根据这四张商品图写一段带货视频的 prompt
写一个从用户评论里提取标签的节点 prompt，要输出 JSON
帮我改一下这个 prompt，它总是多输出一堆解释文字
```

---

## Application

### Step 1 · 判定类型与复杂度

**第一层：按输出消费者判定类型**

| 类型 | 特征 | 模板 |
|---|---|---|
| **A. 生成类** | 输出是图像/视频/音频，消费者是人 | [模板 A](#模板-a生成类视频图像) |
| **B. 结构化输出类** | 输出是 JSON/字段，消费者是下游程序 | [模板 B](#模板-b结构化输出类) |
| **C. 对话类** | 多轮交互，输出是自然语言 | [模板 C](#模板-c对话类) |

判定依据：**问「谁消费这个输出」**。人看 → A 或 C；程序解析 → B。

**第二层：A 类需再判复杂度（决定用一段式还是三段式）**

从两个维度看事件密度，**而不是看素材数量**：

| 维度 | 「少」 | 「多」 |
|---|---|---|
| **时间维度** | 单一连续动作、一段展示 | 多事件链、状态转折、对话往返 |
| **空间维度** | 单一场景固定机位 | 场景切换、跟随穿越、多机位 |

- **两个维度都「少」→ 路径 A1（一段式）**：即使台词长、动作有细节，只要在同一时空连续完成，仍走 A1。例：博主固定位置介绍产品、人物窗边吃蛋糕、商品 360° 展示。
- **任一维度为「多」→ 路径 A2（三段式）**：多事件链、空间切换、跨场景叙事、用户输入已含"镜头1/镜头2"。例：进门→对话→打闹、街巷→集市→翻墙。
- **编辑/延长/替换类任务一律走 A1**：本质是单点操作，不需要三段式。

> 素材数量 ≥4、用户主动写"镜头1/2/3"只是**倾向复杂**的信号，仍要回到时间/空间维度判断。

### Step 2 · 素材角色映射（A 类专用）

多素材生成任务的首要失败模式是**模型把不同素材的角色混为一谈**（把场景图当商品、把包装图当主体）。因此每个素材必须显式声明它承担什么角色。

| 规则 | 说明 |
|---|---|
| **按上传顺序编号，不重新编号** | `@图片1` `@图片2` `@视频1` `@音频1`，与用户输入顺序严格对应 |
| **每个素材写清它提供什么** | ❌「参考这几张图」<br>✅「Picture1 提供商品真实外观与质感；Picture2 锁定包装、品牌与可辨认文字；Picture3 提供手持与尺寸细节；Picture4 提供拍摄环境与光线氛围」 |
| **禁止用「某张图」这类含糊称呼** | 含糊指代会让模型自行分配角色 |
| **重要素材前置** | 越需要精准参考的素材（如人脸大头照）在 Prompt 里位置越靠前 |
| **素材数量不要用满上限** | 推荐 4-5 个：角色图 1-2 + 场景图 1 + 运镜参考视频 1 + 音频 1 |

**人脸参考的素材配置**

| 做法 | 说明 |
|---|---|
| ✅ 大头照（仅头部、无表情）+ 全身照 | 前者锚定面部特征，后者锚定妆造体态 |
| ❌ 三视图 / 多视图 | 多视图易触发 ID 漂移与双胞胎效果 |
| 长图 / 九宫格 | 必须先拆分为单图 |
| 参考人物 > 4 人 | 先分组生图（每组 ≤4 人）再图生视频 |

### Step 3 · 关键歧义拦截

**只有以下四类情况必须停下来问用户**，其余缺失自动补全并披露：

| 歧义类型 | 表现 |
|---|---|
| **方位/帧位映射不明** | 多人或多图未指明谁在左/右、哪张是首帧/尾帧 |
| **任务类型误判风险** | 编辑/延长任务里写了"参考 @视频N"（应为"严格编辑"/"向后延长"） |
| **运镜冲突** | 同一镜头内同时要求推 + 拉 + 摇 + 移 |
| **主体特征自相矛盾** | 同一主体被赋予冲突的静态特征 |

其余项（场景、光影、画质、风格）按 [默认策略](#缺失项默认策略) 自动补全。

### Step 4 · 事实边界检查

**只有用户明确提供或素材中清晰可见的信息才能进入 Prompt。**

| 严禁自行补写 | 说明 |
|---|---|
| 价格、规格、重量、数量 | 未提供就不写 |
| 功效、功能、成分 | 不从商品类别推导功效 |
| 品牌名、认证、资质 | 图中文字模糊时写"以参考图可见文字为准" |
| 优惠、赠品、售后权益 | 不自行补写任何承诺 |

用户文案中的营销夸张语句**可以作为口播原文保留**，但不得据此推导出新的事实。

### Step 5 · 挂载约束包

按场景从 [约束包库](#约束包库) 中挂载。**画质包 + 稳定包 + 水印Logo兜底为默认必挂。**

### Step 6 · 过自检清单 → 输出

输出格式固定为：

```
【生成的 Prompt】
（可直接复制使用的完整内容，放在代码块里）

【关键设计说明】
- 2-4 条，只说非显而易见的设计决策及其原因

【自动补全的信息】
- 列出用户未提供、由本 skill 按默认策略补齐的项（无则省略）

【调优建议】
- 效果不达预期时，优先调整哪一部分
```

## 五要素构造规则

三个模板共用的底层规则。

### Role · 角色

| 规则 | 说明 |
|---|---|
| 用职业身份，不用能力描述 | ✅「你是一名短视频平台的资深内容运营」<br>❌「你擅长写吸引人的文案」 |
| 加平台/场景限定词 | 「电商客服」→「快手电商售后客服」，限定词带出平台特有表达习惯 |
| 多节点链路各节点用不同 Role | 「导演」自带叙事节奏判断，「运营」自带传播效果判断 |

### Task · 任务

| 规则 | 说明 |
|---|---|
| 写产出物，不写动作 | ✅「选出 5 个片段并说明入选理由」❌「分析这些素材」 |
| 一个 Prompt 一个产出物 | 多产出物拆成多个节点，否则靠后的任务会被敷衍，且无法定位失败点 |
| 主观判断必须给依据和优先级 | 「最精彩」不可执行，要展开为带优先级的判定列表 |

### Context · 上下文

| 规则 | 说明 |
|---|---|
| **语义空间不重叠** | 多来源信息拼进同一个 Prompt 时，各自描述的维度不能交叉。<br>例：内容标签只描述"拍了什么"，严禁出现"搞笑/治愈/吐槽"这类带风格语义的词——否则与用户选的风格标签冲突，模型随机二选一 |
| **每个字段写失效条件** | 每个字段都要回答"什么条件下不该用它"。<br>例：上游推荐结果 → 用户已有显式输入时不该用；历史对话 → 超过 N 轮或话题切换时不该用 |
| 做减法测试 | 每个字段问"去掉它效果会变差吗"。字段越多，成本越高、注意力越稀释、冲突概率越大 |

### Rules · 规则

| 规则 | 说明 |
|---|---|
| **反面清单优于正面要求** | 具体的禁止项遵循度高于抽象的正面要求。<br>❌「文案要具体生动」<br>✅「禁止输出：美好/精彩/难忘/治愈（无信息量形容词）、这就是生活/记录美好时光（空泛总结句）、绝了/爱了/yyds（平台黑话）」 |
| **模糊词翻译成结构约束** | 「粒度细」「具体」「生动」不可执行，要翻译成可判定的结构。<br>例：「标签要具体」→「每个标签必须由『人群属性 + 场景 + 需求』三维度组合，缺任一维度视为无效」 |
| **抽象概念外化为可观察细节** | 情绪、气质类词汇必须落到身体细节。<br>「悲伤」→「肩膀微微颤抖、眼眶泛红、手指攥紧衣角」<br>「有销售感」→「面对镜头、拿起商品、指向产品、微笑」 |
| Few-shot 成对给，且说明原因 | 只给正确示例，模型学到的是表面模式；给出「✅ 正确（因为…）/ ❌ 错误（因为…）」才是判断标准 |

### Format · 输出格式

| 规则 | 说明 |
|---|---|
| 结构定义 + 一个完整示例 | 只给字段说明不给示例，格式错误率明显更高 |
| 字段约束就近写 | 「reason 不超过 20 字」写在字段示例旁，遵循度高于写在 Rules 里 |
| **必须定义「无结果」怎么表达** | 不定义的话模型会用自然语言解释为什么没结果，下游解析直接失败 |
| 嵌套不超过 3 层 | 超过 3 层格式错误率上升，宁可拆成两个节点 |
| 结构化输出必写三条禁令 | ①不加前置说明后置总结 ②不用代码块包裹 ③不输出思考过程 |

## 模板 A：生成类（视频/图像）

生成类 Prompt 的核心原则：**把「保持什么」和「改变什么」分开写清楚，并用工程型指令而非形容词堆砌来表达。**

### ⚠️ 先确认：时间表达方式是模型特定的

不同视频生成模型对时间的支持完全不同，**这一项写错会直接导致结构崩坏**：

| 模型 | 时间表达 | 写法 |
|---|---|---|
| **MiniMax H3 系** | 支持绝对秒数 | `0-3秒：… 3-7秒：… 7-11秒：… 11-15秒：…` |
| **Seedance 2.0 系** | **不支持**绝对秒数 | `镜头1：… 镜头2：… 镜头3：…` |
| 未知模型 | 保守做法 | 用镜头序号 + 相对时长比例，不写绝对秒数 |

**默认策略**：用户未指明模型时，用镜头序号；明确是 H3 类模型时用时间轴。

### 路径 A1：单镜/单点操作（一段式）

适用于时间和空间维度都「少」的场景，以及全部编辑/延长/替换类任务。**不要强行拆分块标题**，直接组装为一段：

```
[任务主句] + [主体与素材绑定] + [场景与动作] + [风格与约束包]
```

不同任务的主句写法：

| 任务 | 主句 | 注意 |
|---|---|---|
| 参考生成 | `参考 @图片1 中的<主体1>，生成…` | — |
| 编辑替换 | `严格编辑 @视频1，将其中的 X 替换为 @图片1 中的 Y，动作和运镜不变` | **不要写"参考 @视频1"**，会被误判为参考任务 |
| 延长续写 | `向后延长 @视频1，生成…` | 同上 |
| 组合任务 | `参考 @图片1 的 [维度]，严格编辑 @视频1，[编辑内容]` | — |

**示例**

```
参考 @图片1 中的<主体1>（短发女孩），生成她坐在窗边咖啡店里专注吃蛋糕的
画面，暖黄色光线柔和洒落。高清电影质感，画面稳定无变形，保持无字幕，
不要生成水印，不要生成 Logo。
```

### 路径 A2：多镜头叙事（三段式）

适用于时间或空间维度为「多」的场景。三段必须齐全：

```
【第一段：总体设定 + 主体定义】
- 一句话定调整体场景与氛围
- 一次性绑定全部主体与素材：<主体N>@图片N
  或：将 @图片N 中的[2-3个稳定静态特征] 定义为 <主体N>
- 人脸参考策略：<主体1> 的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）
- 首尾帧约束（如适用）：@图片N 作为首帧约束
- 运镜参考来源（如有）：运镜参考 @视频1 的中景推拉与轻微摇移

【第二段：镜头分镜】
镜头1 / 镜头2 / 镜头3…（或时间轴，取决于模型）
每镜按四要素组织：运镜方式 → 主体动作与表情 → 位置/空间变化 → 音频信息
- 单镜头只指定 1 种运镜（推/拉/摇/移/固定/跟拍择一），禁止叠加
- 动作要肢体细化 + 程度量化（手/腿/头/肩背 + 幅度/速度/力度）
- 优先低缓连续小动作，规避狂奔/大跳/剧烈翻滚等高爆发动态
- 补充动作过渡衔接（如"借着转身惯性顺势抬手"）
- 情绪用身体细节表达，不用抽象词

【第三段：风格 + 约束包】
- 整体美术调性
- 从约束包库挂载
```

### 素材绑定语法

多素材生成的核心是让模型知道**每个素材和每个主体的对应关系**。

| 场景 | 写法 |
|---|---|
| 单主体、未提前定义 | `<主体1>@图片1`，强调绑定关系 |
| 多主体或需复用 | 先定义 `将 @图片1 中的[短发、圆脸、白色衬衫] 定义为 <主体1>`，之后全程用 `<主体1>` |
| 同一主体多素材 | `将 @图片1 中的[面部特征]、@图片2 中的[服装体态] 定义为 <主体1>` |

**两条必须遵守的语法约束**

| 约束 | 说明 |
|---|---|
| **禁止裸写素材 ID** | 底层模型无法关联无语义的 `[asset-xxxx]`，必须通过 `@图片N` / `<主体N>` 桥接 |
| **断句防歧义** | `@图片N` 后紧接动词或方位词会触发数字粘连歧义。<br>❌ `@图片1跑向…`　❌ `@图片2位于…`<br>✅ `<主体1>@图片1 跑向…`　✅ `@图片1 中的女子位于…` |

### 特殊信息的符号隔离

不同类型的音视频信息用不同符号包裹，避免模型混淆（Seedance 2.0 系语法，其他模型需确认）：

| 信息类型 | 符号 | 示例 |
|---|---|---|
| 背景音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}` |
| 字幕/标题 | `【】` | `【第一章：启程】` |

### 音频通道处理

| 项 | 做法 |
|---|---|
| 音色参考 | `参考 @音频1 中的音色，生成…`；还原度不佳时补充细致描述（如"低厚温润带细碎颗粒感的中年男声"） |
| 语种统一 | 避免中英混用（专有名词除外）；小语种需标注语种，如 `用日语说道 {こんにちは}` |
| 中文发音兜底 | 多音字/生僻字易读错，改写为发音一致的常用同音字（"螭龙山"→"吃龙山"），并在披露中说明 |

### 文字生成三模板

| 类型 | 模板 |
|---|---|
| 广告语 | `「文字内容」+「出现时机」+「出现位置」+「出现方式」+「文字特征（颜色、风格）」` |
| 字幕 | `画面底部出现字幕，字幕内容为"…"，字幕需与音频节奏完全同步` |
| 气泡 | `<主体1>说："…"，说话时周围出现气泡，气泡里写着台词` |

## 约束包库

按场景挂载。**前三个为默认必挂。**

| 约束包 | 何时挂 | 内容 |
|---|---|---|
| **画质包** | 默认必挂 | `高清，细节丰富，电影质感，色彩自然，光影柔和` |
| **稳定包** | 默认必挂 | `人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿` |
| **水印/Logo 兜底** | 默认必挂 | `不要生成水印；不要生成 Logo` |
| **字幕兜底** | 非文字生成任务必挂 | `保持无字幕，避免生成任何文字或字幕` |
| **双胞胎兜底** | 多人/多主体场景必挂 | `全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物` |
| **风格锚定** | 动漫/非写实场景必挂 | 显式写出 `2D 日漫风格` / `3D 国风漫画` / `赛博朋克冷蓝紫色调`，防止漂移到写实 |
| **强方位约束** | 多人正面动态场景 | 明确写"左侧角色穿灰蓝色作训服"等强方位描述，配合固定机位避免穿模/跳脸 |
| **商品一致性包** | 电商/商品类必挂 | `商品形状、颜色、包装、Logo、文字和关键细节以参考图为准，不得臆造、替换或改写；避免包装变形、文字乱码` |
| **人物一致性包** | 有人物且跨镜头时必挂 | `全片始终是同一位人物，面部、发型、服装、体态和气质保持一致；避免人物换脸、手指畸形` |

## 缺失项默认策略

用户未提供时按此补全，并在【自动补全的信息】中披露。

| 要素 | 必要性 | 缺失时的默认 |
|---|---|---|
| 精准主体（谁） | **必填** | 按 Step 2 建立 `<主体N>@图片N` 绑定；仅有泛指时保留泛指并标记 |
| 动作细节（干什么） | **必填** | 采用低缓连续小动作，按肢体细化 + 程度量化补全 |
| 场景环境（在哪） | 按需 | A1 可省略或一句话带过；有场景素材时按其推断 |
| 光影色调 | 按需 | A1 合并入风格短语；A2 第一段一句话定调 |
| 镜头运镜 | 按需 | A1 可不写（模型默认稳定运镜）；A2 每镜必填，一镜一运镜 |
| 视觉风格 | 按需 | 优先用户指定；未指定按整体感觉与素材画风推断；**动漫/非写实场景升为必填** |
| 画质 | 按需 | 挂画质包；A1 可压缩为"高清电影质感" |
| 画幅与时长 | 按需 | 默认竖屏 9:16、15 秒（短视频基准）。**画幅要写死，不依赖模型从参考素材推断** |
| 约束条件 | 按需 | 默认挂画质包 + 稳定包 + 水印Logo兜底；**多人/文字生成场景升为必填** |

## 完整示例：视频复刻

**输入**

> 给我生成一段用于视频复刻的 prompt，视频结构需与参考视频一样，人物替换成我自己

**判定**：A 类（生成）→ 单点操作（人物替换）→ 路径 A1，但因保持项多，采用结构化的 A1 变体

【生成的 Prompt】

```
严格编辑 @视频1，将其中的主体人物替换为 @图片1 中的<主体1>，
其余全部保持不变。

必须严格保持（与 @视频1 完全一致）：
1. 镜头结构：分镜数量、顺序、每个镜头的时长比例
2. 运镜方式：每个镜头的推/拉/摇/移类型、速度、幅度
3. 剪辑节奏：转场时机、转场类型、与背景音乐节拍的对齐关系
4. 构图与景别：主体在画面中的位置、每个镜头的景别（远景/中景/近景/特写）
5. 光影与色调：光源方向、明暗对比、整体色温与调色风格
6. 背景环境：场景、道具、背景元素

替换 <主体1> 时须保持以下不变：
- 人物在每个镜头中的画面位置与占比
- 人物的朝向、视线方向
- 人物的动作类型与幅度
- 人物与背景的遮挡关系和空间层次

严格禁止：
1. 禁止增加或减少分镜数量，禁止改变分镜顺序
2. 禁止添加 @视频1 中不存在的转场、特效、贴纸、滤镜
3. 禁止在画面中生成任何文字、字幕、水印、Logo
4. 禁止改变画幅比例
5. 禁止改变整体色调风格
6. 禁止生成 @视频1 中不存在的场景或道具

输出规格：9:16 竖屏，时长与 @视频1 完全一致，帧率一致。

高清，细节丰富，电影质感，色彩自然，光影柔和；人物面部稳定不变形、
五官清晰、动作连贯自然，不僵硬，无穿模无卡顿；全片始终是同一位人物，
面部、发型、服装、体态保持一致，避免人物换脸、手指畸形；保持无字幕，
不要生成水印，不要生成 Logo。
```

【关键设计说明】

- **用「严格编辑 @视频1」而非「参考 @视频1」**：替换类任务写"参考"会被判为参考生成任务，导致模型自由重构而非精确复刻
- **保持项拆成 6 个可独立判定的维度**：笼统写"结构一致"模型无法执行，拆开后每项能单独对齐
- **替换项显式声明 4 项「跟着不变」**：只说"换人"时模型常连带改变人物位置和动作幅度，导致结构偏离
- **禁止生成文字单独列条**：生成模型常自行添加字幕，若下游还要叠加字幕会出现双字幕

【自动补全的信息】

- 画幅：按短视频场景默认 9:16，参考视频为横屏请改为 16:9
- 按"仅替换人物"处理，未涉及场景/商品替换
- 已挂载画质包、稳定包、人物一致性包、字幕兜底、水印Logo兜底

【调优建议】

- 结构偏离参考视频 → 检查"必须严格保持"是否覆盖了偏离的那个维度
- 人物替换后动作变形 → 强化替换项下的保持项，可补充具体动作描述
- 画面仍出现文字 → 参考视频若自带字幕，需在生成前使用字幕擦除处理，仅靠 Prompt 无法可靠消除
- 竖屏效果显著差于横屏 → 属模型在该画幅上的能力分布问题，Prompt 无法解决

## 完整示例：电商带货（多素材 + 时间轴）

**输入**

> 四张商品图（商品图1、商品图2、补充图、场景图）+ 人物描述 + 文案，生成 H3 带货视频 prompt

**判定**：A 类 → 多镜头 → 路径 A2；模型为 H3，**使用时间轴**

【生成的 Prompt 结构】

```
基于四张参考图生成一条15秒竖屏电商带货短视频（9:16），[整体拍摄质感]，
人物和商品保持全片连续一致。

素材角色严格对应：
Picture1 为商品图1，提供[真实商品外观/口感质感]；
Picture2 为商品图2，锁定[包装、品牌、颜色、版式与可辨认文字]；
Picture3 为补充图，提供[手持、独立包装、内部结构、尺寸细节]；
Picture4 为场景图，提供[最终拍摄环境、桌面布置、光线氛围]。
商品形状、颜色、包装、Logo、文字和关键细节以参考图为准，不得臆造、
替换或改写。

人物：[完整人物描述——年龄范围、脸型、肤色、妆容、服装、发型、体态]。
全片始终是同一位人物，面部、发型、服装、体态和气质保持一致。

时间轴与普通话口播/字幕：
0-3秒：[人物面对镜头 + 商品快速亮相]，口播/字幕："[黄金Hook]"
3-7秒：[商品近景/掰开/质感细节]，口播/字幕："[核心卖点]"
7-11秒：[多件商品/包装/规格/使用场景]，口播/字幕："[规格或场景]"
11-15秒：[人物与商品同框]，口播/字幕："[行动号召]"

镜头语言：[景别、运镜、光线、声音、节奏]。字幕简洁清晰，准确呈现上述口播。

一致性约束：人物面部/发型/服装/体态一致；商品形状、颜色、包装、Logo、
文字一致；四图角色不串位；避免包装变形、文字乱码、手指畸形、人物换脸、
场景跳变；不出现额外人物、品牌或设备；不要生成水印。
```

【关键设计说明】

- **四图角色逐一显式声明**：不声明时模型会把场景图当成商品、把包装图当成主体，这是多素材生成的首要失败模式
- **人物设定放在时间轴之前，且声明"全片一致"**：只在第一个镜头写人物描述会导致后续镜头 ID 漂移
- **文案分配到四段时间轴，而不是整段堆在末尾**：堆在末尾会生成静态商品展示，分配到时间轴才能转成可执行镜头
- **约束里包含"四图角色不串位"**：这是多素材场景特有的失败模式，需显式禁止

## 生成类常见问题与对策

| 问题 | 对策 |
|---|---|
| 生成结果与参考视频结构不一致 | 检查保持项是否拆到了独立可判定的维度，笼统写"结构一致"无效 |
| 模型自由重构而非精确复刻 | 检查是否误用了"参考 @视频N"，替换/编辑类必须写"严格编辑 @视频N" |
| 人物替换后位置/动作变了 | 替换项下补充「保持位置、朝向、动作幅度、空间层次不变」 |
| 多素材角色串位（场景当商品） | 逐一显式声明每个素材承担什么角色，禁用"某张图"这类称呼 |
| 跨镜头人物 ID 漂移 / 出现双胞胎 | ①人脸用大头照+全身照，禁用三视图 ②挂双胞胎兜底 ③全程用同一 `<主体N>` 标签 |
| 画面出现多余文字或字幕 | 挂字幕兜底；若原视频自带字幕，需在生成前用字幕擦除处理，**仅靠 Prompt 无法可靠消除** |
| 多人正面场景穿模/跳脸 | 强方位约束 + 固定机位 + 双胞胎兜底 |
| 动作变形、肢体异常 | 改用低缓连续小动作，规避狂奔/大跳/剧烈翻滚 |
| 风格漂移到写实（动漫场景） | 风格锚定升为必填，显式写出风格词 |
| 包装文字乱码 | 挂商品一致性包；图中文字模糊时写"以参考图可见文字为准"，不要试图让模型生成清晰文字 |
| 时间轴不生效、结构崩坏 | 确认模型是否支持绝对秒数。Seedance 2.0 系必须改用镜头序号 |
| 运镜混乱 | 一镜一运镜，禁止在同一镜头叠加推拉摇移 |
| 输出画幅错误 | 显式写死画幅，不依赖模型从参考素材推断 |
| 横屏正常、竖屏效果差 | 模型在该画幅上的能力分布问题，Prompt 无法解决，需换模型或补前置处理 |
| 台词发音错误 | 多音字/生僻字改写为同音常用字，并在披露中说明 |
| 片尾出现截断杂音 | 属模型特性，建议后期用音量包络线做淡出 |

## 结构化输出常见问题与对策

| 问题 | 对策 |
|---|---|
| 输出前后带解释文字 | Prompt 加格式禁令三条；**同时**在解析侧用正则抽取首个 JSON 对象 |
| 输出混入思考过程 | 优先检查模型参数中思考模式是否**显式**关闭（不是"不覆盖走默认值"）；Prompt 侧加禁令；解析侧剥离 `<think>` 块 |
| 输出粒度过粗（只返回"女性""年轻"） | 把模糊要求翻译成维度强制组合，并给成对示例 |
| 枚举字段返回范围外的值 | Format 中列出完整枚举，并加「只能从以上取值中选择」 |
| 无结果时返回自然语言 | Format 末尾补空结果定义（**最常被遗漏的一条**） |
| 偶发格式错乱 | Prompt 侧降低发生率，解析侧降低影响面，**两侧都要做** |

## 自检清单

**通用**
- [ ] Role 是职业身份 + 场景限定词，不是"专业助手"
- [ ] Task 写的是产出物，不是动作
- [ ] 一个 Prompt 只有一个产出物
- [ ] 所有主观判断都给了明确依据
- [ ] 所有模糊词（具体/生动/粒度细/有销售感）都翻译成了结构约束或可观察细节
- [ ] Rules 里有具体的反面清单，不只有正面要求
- [ ] 多来源 Context 的语义空间不重叠

**A 类补充**
- [ ] 已确认目标模型的时间表达方式（绝对秒数 vs 镜头序号）
- [ ] 每个素材都显式声明了它承担什么角色
- [ ] 没有裸写 `[asset-xxx]`，全部通过 `@图片N` / `<主体N>` 桥接
- [ ] `@图片N` 后没有紧接动词或方位词
- [ ] 编辑/延长任务用了"严格编辑"/"向后延长"，没有误写"参考"

- [ ] 保持项拆到了可独立判定的维度（不少于 4 项）
- [ ] 替换项写清了"什么跟着变、什么不变"

- [ ] 字段约束就近写在字段旁

## 诊断：Prompt 改不动的时候

**改 Prompt 之前先判断这是不是 Prompt 能解决的问题。**

| 现象 | 是 Prompt 问题吗 | 该做什么 |
|---|---|---|
| 同一输入跑 5 次，有成功有失败 | ✅ 是 | 加约束，收窄输出空间 |
| 同一输入跑 5 次，5 次全失败 | ❌ 能力缺失 | 换模型，或在产品层规避 |
| 某一类输入（如竖屏）全部失败 | ❌ 输入分布问题 | 前置处理，或换模型 |
| 输出格式偶发错乱 | ⚠️ 部分是 | Prompt 侧 + 解析侧都做 |
| 输出混着思考过程 | ❌ 参数配置问题 | 检查思考模式是否显式关闭 |
| 原视频自带字幕消除不掉 | ❌ 需前置处理 | 接字幕擦除，Prompt 无法可靠消除 |

**「同一输入跑 5 次」是成本最低的诊断动作**，能区分"能力缺失"和"能力不稳定"这两类需要完全不同处理的问题。

## 调优方法

**一次只改一处**，并记录：

| 版本 | 改了什么（只一处） | 测试集通过率 | 结论 |
|---|---|---|---|
| v1 | 基线 | 62% | — |
| v2 | 加禁用词清单 | 78% | ✅ 留 |
| v3 | 加 Few-shot 错误示例 | 85% | ✅ 留 |
| v4 | Role 改为资深运营 | 84% | 无影响，可回退 |

一次改多处时效果变化无法归因，下次遇到同类问题无法复用结论。这张表本身也是 Prompt 的版本管理。
