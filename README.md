# AI 产品实习笔记

> 我在快影（快手旗下剪辑工具）做 AI 产品实习生期间，把踩过的坑和摸索出的做法整理成了几个能重复用的工作模板。
>
> 这不是方法论总结，只是一份**能让我下次做同类需求时少走弯路的笔记**。

---

## 关于我和这份笔记

我是 2027 届硕士，在快影事业部做 AI 产品实习。参与的主要是两个功能：

- **智能剪辑**——把用户手机里的一堆素材自动剪成一条成片，六个节点的工作流（高光识别 → 剪辑思路 → 片段排序 → 文案生成 → 封面生成 → 智能包装）
- **爆款复刻**——用户传一条爆款视频，生成同风格的新视频，核心是 Seedance 2.0

实习之前我以为 AI 产品的难点是「怎么写好 Prompt」。做完之后发现，**Prompt 只占我实际工作量的一小部分**，更多时间花在了这些事上：

- 为什么这个需求要用大模型做，而不是用模板做（评审会上被问了三次）
- 提测时 badcase 率 70%，但上游团队测 50 个视频一个问题都没有，问题到底在哪
- 效果「好不好」怎么变成一个能写进周报的数字
- 灰度到 30% 转化率上不去，该继续放还是停下来

这些问题我当时基本是现学现做的，很多判断是错的，改了好几遍。这份笔记就是把改对的那些留下来。

## 需要说明的局限

写完之后我自己重读了一遍，觉得有几点必须讲清楚，否则会显得我在装懂：

**① 样本量是 1**

我只在一家公司、一条产品线上做过 AI 产品。里面所有的「规律」严格来说只是「我在这个项目里观察到的现象」。比如「视觉理解节点占 90% 成本」这条，在我做的智能剪辑里确实是这样，但换成别的产品结构可能完全不同。

**② 很多判断不是我一个人做的**

模型选型、节点拆分这些决策是和算法、研发一起讨论出来的。我在笔记里写「我们的做法是」而不是「我的方法是」，是因为确实如此。

**③ 有些结论我还没验证完**

比如爆款复刻卡在 30% 时我们同时做了模型调研和模板方案，哪条路最终更有效，我实习结束时还没有结论。这类地方我都标注了。

**④ 数据已脱敏**

所有涉及内部数据的地方都做了处理——成本用公开模型定价重新算了一遍等价示例，只保留比例关系；具体业务数据不写。

## 为什么要公开这个

一是我自己下次做类似需求时会翻。这些东西如果只存在飞书里，换个环境就找不到了。

二是我发现网上关于 AI 产品的内容基本分两种：讲 Prompt 技巧的，和讲行业趋势的。中间那层——**具体某个需求怎么从想法推到上线、中间会遇到什么**——几乎没有人写。我作为一个刚入门的人非常需要这种东西，所以自己写了一份。

如果你也在做 AI 产品，欢迎提 Issue 告诉我哪里写错了。我大概率会有很多地方是错的。
